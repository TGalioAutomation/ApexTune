Tính năng

Một icon, cả bộ công cụ

Không có icon Dock, không cửa sổ treo lơ lửng — mọi thứ mở ra từ menu bar và biến mất khi bạn xong việc.

Dashboard menu bar

Điểm sức khỏe hệ thống, GPU · CPU · DISK · RAM · NET · Pin trực tiếp trên status item, 5 theme banner, 3 profile sampling.

Gỡ cài đặt sạch sẽ

Gỡ app kèm toàn bộ file rác còn sót: preferences, caches, container — có preview và xác nhận trước khi xóa.

Dọn sâu & tập tin lớn

Smart Clean, Junk Cleaner, Deep Clean, dò file lớn và logs cũ — quét song song, phân loại rõ ràng.

Bảo vệ thời gian thực

Chặn quảng cáo & tracker qua /etc/hosts, quét malware/adware phổ biến, tự backup & khôi phục an toàn.

Cảnh báo RAM thông minh

Ngưỡng RAM toàn hệ thống tuỳ chỉnh (60–95%), chỉ đích danh app nặng nhất, buộc thoát có xác nhận.

Xóa vĩnh viễn an toàn

File shredder nhiều lượt, whitelist đường dẫn hệ thống, chặn xóa nhầm thư mục gốc.

Space Lens & Docker

Trực quan hoá ổ đĩa, dò thư mục phình to; dọn image Docker và model AI (Ollama, LM Studio) lấy lại hàng chục GB.

Riêng tư

Quét lịch sử duyệt web, cookies, dấu vết nhà phát triển — chỉ đếm và xóa tại chỗ, không gửi dữ liệu đi đâu.

Song ngữ Việt–Anh

UI tiếng Việt hoàn chỉnh (mặc định theo ngôn ngữ hệ thống), chuyển ngay trong Cài đặt; thêm ngôn ngữ = 1 file JSON.
